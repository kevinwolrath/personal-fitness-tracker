# Body Anvil achievement artwork (#73)

`forge-emblem.png` is a reusable production badge/celebration illustration, generated with the built-in ImageGen tool on 9 November 2026. It is gender-neutral and uses no new character art. Text, locked states and achievement identity are rendered accessibly by the application, outside the bitmap.

The original approved reference PNG was absent from `docs/design/issue-73-gamification/achievement-reference.png`; this new asset follows the owner's explicit authorization to continue with the written design direction and existing Hero Forge palette. It is not a copy of that missing reference.
